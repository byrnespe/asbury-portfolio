# LineWatch / Hows The Q

**What it is.** A nightlife status app ("how's the queue?") — an Expo/React Native
client plus a Vite/React web frontend backed by a TypeScript API server with auth,
rate limiting, and Neon Postgres. Deploy target: Railway.

**Stack.** TypeScript, Expo/React Native, Vite/React, Node API, Clerk auth,
Neon Postgres, Railway.

**What it demonstrates.**
- Full-stack mobile + web + API in one workspace.
- Auth, rate limiting, and security headers in the API layer.
- Managed-Postgres (Neon) integration.

**Status.** Prototype — developed, not launched.
