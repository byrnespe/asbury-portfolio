# VeilTrace

**What it is.** A property-ownership intelligence product. Performs LLC-piercing
research on a property, produces an AI-assisted intelligence report, and delivers it
as a formatted PDF. Built across three surfaces: Flask backend, Electron desktop, and
an iOS workspace.

**Stack.** Python, Flask, LLM/AI research, ReportLab PDF, Stripe billing, auth,
Electron, React Native/Expo, Docker.

**What it demonstrates.**
- A full product across three surfaces (backend + desktop + mobile).
- Applied AI research producing a real, paid-standard deliverable (DeepSight report).
- Production concerns: billing, auth, compliance, fulfillment, PDF generation at scale.

**Status.** Pilot (pre-revenue) — real report deliverables produced.

**Source.** `~/projects/veiltrace/` (backend + electron + docker), `~/projects/veiltrace-app/` (deliverables + docs).
