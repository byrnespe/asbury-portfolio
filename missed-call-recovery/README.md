# Missed-call recovery (MCR)

**What it is.** A telephony lead-recovery tool: detects missed calls and triggers
follow-up outreach so no lead falls through the cracks. Shipped as a Python package
with an install script, runbook, and tests.

**Stack.** Python, Twilio (telephony), `install.sh`, pyproject packaging, runbook.

**What it demonstrates.**
- Telephony-driven lead recovery automation.
- Packaged install + operational runbook discipline.

**Status.** Built; pre-production.

**Source.** `~/projects/missed-call-recovery/` (`mcr/`, `install.sh`, `RUNBOOK.md`).
