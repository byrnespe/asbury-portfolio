# Quote-to-invoice

**What it is.** A business-document automation engine that converts a service quote
into an invoice — part of the Asbury dealership/service ops automation suite.

**Stack.** Python package (`qti`), tests.

**What it demonstrates.**
- Business-document automation with a tested engine.
- Clean package structure for a small, focused engine.

**Status.** Built; internal tooling.
