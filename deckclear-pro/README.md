# Deckclear Pro

**What it is.** A Windows performance dashboard — 42 one-click, reversible performance
tweaks (Turbo Boost, cooling, power plans, RAM trim, disk cleanup) with live CPU/RAM
monitoring. Built by Asbury Solutions; marketed under the "Deckclear" consumer brand.

**Stack.** PowerShell + WPF (Windows app), plus a Python/web variant (FastAPI server +
HTML dashboard + hardware-controls config).

**What it demonstrates.**
- Native Windows systems programming with reversible, self-reverting tweaks.
- A web-served control dashboard and hardware diagnostics.
- Store-listing and packaging discipline (installer, marketing assets).

**Status.** Built and packaged; store listing prepared (pre-launch).

**Source.** `~/projects/pcboost/` (PowerShell + installer + store), `~/projects/pc-boost/` (Python/web variant).
