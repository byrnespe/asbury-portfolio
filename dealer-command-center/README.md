# Dealer Command Center

**What it is.** A dealership operations command center: a PowerShell/WPF desktop app
that consolidates dealer operations into one control surface, shipped with an
installer, launcher, and product/strategy documentation.

**Stack.** PowerShell, WPF, Windows launcher/installer (.bat/.vbs), product + strategy docs.

**What it demonstrates.**
- Native desktop product delivery for a vertical (dealership ops).
- Packaging + launch UX (launchers, installer).
- Product/strategy discipline (pitch, quickstart, product doc).

**Status.** Delivered to staging.

**Source.** `~/projects/dealer-command-center/` (`DealerCommandCenter.ps1`, installer, deliverables).
