# Twilio voice agent

**What it is.** A voice/AI telephony agent over Twilio: call handling, voicemail,
and a documented public webhook path. Includes deploy scripts and a recorded
voicemail greeting artifact.

**Stack.** Python (server), Twilio, TTS/STT, deploy + start scripts.

**What it demonstrates.**
- Voice/AI application engineering on a real telephony provider.
- Twilio webhook integration with a documented public path.
- Audio artifact handling (voicemail greeting).

**Status.** Built and wired to Twilio (public path documented); pre-production.

**Source.** `~/projects/voice-agent/` (server + deploy), `~/projects/donna-voice-agent/` (greeting + docs).
