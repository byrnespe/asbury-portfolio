# Public Portfolio — Asbury Solutions

Selected build portfolio · prepared 2026-09-29 · Peter Byrnes (Engineering)

Eighteen real, source-verified projects built under `~/projects/`. Each entry has a
`README.md` (what it is, stack, what it demonstrates, one honest status line) and,
where a safe screenshot exists, a `screenshots/` folder. This is a catalog, not a
source dump: no `.git`, `.env`, tokens, `os.db`, `messages.db`, private keys, or
client-specific material are included. Source paths are cited so the code can be
inspected in place.

## Status legend (honest framing)

- **Live** — verified running on this host at the time of writing (health probe returned 200).
- **Pilot** — real product, exercised with real users/inputs, not yet revenue-paying.
- **Staging** — built and delivered to a staging environment, not yet in production.
- **Prototype / internal tooling** — built and working, used internally, not commercially launched.

> Honesty note: this portfolio demonstrates **build capability**, not commercial
> traction. Asbury Solutions records no claimed revenue from these projects, and
> several are staging/pre-revenue. Nothing here fabricates customers, revenue, or
> "live production" status.
