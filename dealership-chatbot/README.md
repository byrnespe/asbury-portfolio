# Dealership chatbot

**What it is.** A white-label dealership AI chatbot: an embeddable React chat widget
with a knowledge/inventory/lead engine backed by Supabase, plus a landing page. Driven
by per-dealer configuration so one codebase serves many dealerships.

**Stack.** React + Vite + TypeScript, Supabase, script-tag embed (`embed.ts`),
config-driven dealer/Asbury settings.

**What it demonstrates.**
- Embeddable AI widget engineering (chat UI + engine + analytics).
- Config-driven white-label product (one build, many dealers).
- Supabase integration for inventory + knowledge + lead capture.

**Status.** Delivered to staging.

**Source.** `~/projects/dealership-websites/chatbot-template/` (app), `~/projects/dealership-chatbot/` (landing + product docs).
