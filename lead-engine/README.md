# Lead Engine

**What it is.** An automated lead-generation pipeline for Monmouth County, NJ:
car-buyer lead finding, a lead dashboard, and autopilot outreach — backed by a
"Lead Truth Engine" Python package and an n8n daily workflow.

**Stack.** Python (engine, models, CLI), n8n workflow, BatchData skip-tracing API.

**What it demonstrates.**
- Lead-generation automation end to end (find → track → outreach).
- Data-enrichment API integration (skip tracing).
- CLI engineering with tests.

**Status.** Operational pipeline (internal use).

**Source.** `~/projects/lead-truth-engine/` (package), `~/projects/org-arch-migration/n8n/workflow-exports/Lead_Engine_Daily_Monmouth.json`.
