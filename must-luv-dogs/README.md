# Must-Luv-Dogs

**What it is.** A pet-sitting platform: a TanStack Start + Electron frontend backed by
Supabase, with a Docker-based deployment variant and a real dependency graph.

**Stack.** TypeScript, TanStack Start, Electron, Supabase, Bun, Vite, Docker.

**What it demonstrates.**
- Modern full-stack (SSR) + desktop packaging.
- Supabase backend integration.
- Containerized deploy configuration.

**Status.** Prototype / in development.

**Source.** `~/projects/must-luv-dogs-app/`, `~/projects/mld-app/` (Docker + backend variant).
