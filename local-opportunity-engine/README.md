# Local opportunity engine

**What it is.** A local-opportunity scoring engine that surfaces local business
opportunities (home services / automotive), with a web API and templates.

**Stack.** Python (`loe` package), Flask web layer, templates, tests.

**What it demonstrates.**
- Opportunity-scoring logic as a tested engine.
- A web surface (API + templates) on top of the engine.

**Status.** Built; internal tooling.

**Source.** `~/projects/local-opportunity-engine/` (`loe/`, `web/`, `tests/`).
